# Download Page UI update

- Added day/night resource values for the downloader page so its surfaces, text, borders and input colors follow the active system theme.
- Reworked the Video/Audio selector so the inactive option is icon-only and the active option reveals its label, with a shared animated blue indicator and touch response.
- Updated the selected blue capsule to a fully filled, layered blue gradient with a subtle edge and ripple.
- Increased bottom scroll clearance and applied system-bar insets to the download page so the Download action can be reached above gesture/navigation areas.

The existing yt-dlp format selection and download callbacks are unchanged.
